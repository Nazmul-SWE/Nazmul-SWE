## Featured work

### [FutureFinds GadgetHub](https://github.com/Nazmul-SWE/FutureFinds_GadgetHub)

An e-commerce platform for browsing, buying, and renting gadgets. It includes flash sales, pre-orders, day-based rentals, SSLCommerz sandbox checkout, and Selenium end-to-end tests.

`Python` `Django` `Tailwind CSS` `SQLite` `Selenium`

### [AI Resume Screening System](https://github.com/Nazmul-SWE/AI_Resume_Screening_System)

An NLP-based screening tool that combines text similarity, classification, and career-trajectory scoring into an interpretable fit score. The Streamlit interface supports screening, ranking, and candidate comparison.

`Python` `scikit-learn` `pandas` `Streamlit` `pypdf`

### [HAR: Signal to Image](https://github.com/rashed501772/har_signal_to_img_2026_spring)

A human-activity-recognition project that transforms SisFall wearable-sensor windows into time-frequency mosaic images and classifies activities with EfficientNetV2-S. Fall-severity anomaly detection is the next step.

`Python` `PyTorch` `scikit-learn` `PyWavelets`
